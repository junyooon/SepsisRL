# SepsisRL

This project implements a Constrained Deep Q-Network (DQN) with a Dueling architecture to learn treatment policies for sepsis. The goal is to maximize patient survival while enforcing clinical safety constraints by penalizing drastic changes in IV fluid and vasopressor dosages. The agent is trained and evaluated using the ICU-Sepsis environment built on the MIMIC-III dataset.

### 1. Clone the Repository

git clone https://github.com/junbuggyTT/SepsisRL.git
cd SepsisRL

### 2. Environment Setup

# It is highly recommended to use a virtual environment (e.g. conda or venv)
conda create -n sepsisrl_env python=3.10
conda activate sepsisrl_env

### 3. Install Required Packages

pip install -r requirements.txt

### 4. Running the Demonstration

1.  **Start Jupyter:**
    ```bash
    jupyter notebook
    ```
2.  **Open the Notebook:** Navigate to and open `project.ipynb`.
3.  **Run All Cells:** Run all cells in the notebook sequentially.

### Output Generated by the Notebook:

The notebook will:
1.  Initialize the ICU-Sepsis environment.
2.  Load the pre-trained Unconstrained DQN and Constrained DQN.
3.  Print the simulated **Estimated Patient Survival Rate** and **Constraint Violation Rate**.
4.  Generate and display visualizations of the **Action Distributions** for both agents.
